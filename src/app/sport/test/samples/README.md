# Sport submission CSV samples

Deze fixtures zijn gebaseerd op echte CSV-output van `Aanmelden sportactiviteit`
uit de ACCP-omgeving, aangemaakt door testautomatisering.

Voor publicatie in de publieke repository zijn persoons- en interne
infrastructuurwaarden vervangen. De kolommen, lege waarden, serialisatie van
samengestelde velden en functionele waarden zoals `stadsdeel`, `appId`,
`aanmeldenSportactiviteit` en `sportactiviteitenData` zijn behouden.

De set bevat:
- alle zeven sportgebieden;
- zowel een kind- als volwassene-aanmelding;
- een volwassene-aanmelding met een daadwerkelijk geselecteerde sportactiviteit.

Gebruik deze bestanden als realistische parser-/mappingfixtures. Pas de fixtures
niet aan om een parser eenvoudiger te maken; als productie-output een afwijkende
vorm heeft, voeg liever een gerichte fixture toe.
